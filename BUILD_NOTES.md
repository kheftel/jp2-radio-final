# JP2 Radio App — What's In This Build

**Version:** 2.2.0 &nbsp;|&nbsp; **Date:** July 16, 2026

---

## In plain terms

This build plays the live radio stream, keeps playing when you switch
screens or lock the phone, sends push notifications, and now also adds
**Android Auto** and **Apple CarPlay** — so the app can show up on a car's
dashboard screen.

Everything except the car features has already been checked and works.
The car features are built and look correct, but **haven't been tested yet**
— that's the one thing left to confirm.

---

## ✅ Already confirmed working

- Live radio stream, plays across all screens
- Keeps playing in the background / with the phone locked
- Push notifications
- Blog, banners, schedule, donate, Open Mic recording
- Code installs cleanly and has zero errors

## 🧪 Needs testing (the main task)

| Feature | Status |
|---|---|
| **Android Auto** | Built and double-checked on paper. Not yet run on a real device/simulator. |
| **Apple CarPlay** | Built. The riskiest part — could need a small fix on the first try. |

**What "needs testing" means in practice:** run it once in each car
simulator and see if the station list shows up and play/pause works. If
something's off, send a screenshot and it'll get fixed.
